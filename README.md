# ABE Agro Hub — www.abeagrohub.com

Agricultural machinery & food-processing equipment, Kasoa, Ghana. *Mechanizing Agriculture. Empowering Nations.*

This repository currently holds the **build starter pack**:

- `BUILD_SPEC.md` — full specification for building the website (stack, pages, Kobby AI assistant, WhatsApp quotes, Hostinger deployment)
- `CLAUDE.md` — working rules for Claude Code
- `content/products.json` — the 39 catalogue products
- `public/products/`, `public/brand/` — product photos and logos
- `reference/` — screenshots of the earlier concept

To build: open this repo in Claude Code and say *"Read BUILD_SPEC.md and start Phase 0."*
